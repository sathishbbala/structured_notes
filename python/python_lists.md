# Lists
In Python, a list is an ordered, changeable (mutable) collection of items that allows duplicate values. Lists are the most versatile and widely used data structure in Python, written using square brackets [].
Think of a list like a dynamic shopping list: you can keep adding items, crossing items out, rearranging them, or changing them at any point.

1. len() function is used to find the number of items in a list.
2. List items can be a string, boolean or an integer.
3. List items are accessed using an index that starts with 0.
   - Negative indexing means start from the end.
4. Range of indexes can be used to slice a list.
5. The insert() method inserts an item at the specified index.
6. The append() method is used to add an item at the end of the list.
7. The extend() method is used to add items from another list, tuple, set or a dictionary
8. The remove() method removes the item from a list.
9. The pop() method removes an item specified by an index.
10. The clear() method empties the list.
